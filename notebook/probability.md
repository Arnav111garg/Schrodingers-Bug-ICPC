# Probability Concepts

## Basic Definitions
- **Probability**: A measure of the likelihood that an event will occur, expressed as a number between 0 and 1.
- **Random Experiment**: An action or process that leads to one or more outcomes.
- **Sample Space (S)**: The set of all possible outcomes of a random experiment.
- **Event (E)**: A subset of the sample space.

## Key Formulas
1. **Probability of an Event**:
   P(E) = Number of favorable outcomes / Total number of outcomes

2. **Complementary Events**:
   P(E') = 1 - P(E)

3. **Addition Rule**:
   For two mutually exclusive events A and B:
   P(A ∪ B) = P(A) + P(B)

4. **Multiplication Rule**:
   For two independent events A and B:
   P(A ∩ B) = P(A) * P(B)

## Types of Probability
- **Theoretical Probability**: Based on reasoning and mathematical calculations.
- **Experimental Probability**: Based on the actual experiments and observations.
- **Subjective Probability**: Based on personal judgment or experience.

## Important Concepts
- **Conditional Probability**: The probability of an event A given that event B has occurred.
  P(A | B) = P(A ∩ B) / P(B)

- **Bayes' Theorem**: A way to find a probability when we know certain other probabilities.
  P(A | B) = [P(B | A) * P(A)] / P(B)

## Common Distributions
- **Binomial Distribution**: Models the number of successes in a fixed number of independent Bernoulli trials.
- **Normal Distribution**: A continuous probability distribution characterized by a bell-shaped curve.
- **Poisson Distribution**: Models the number of events occurring in a fixed interval of time or space.

## Applications
- Probability is widely used in fields such as statistics, finance, gambling, science, and artificial intelligence to make informed decisions based on uncertain outcomes.
